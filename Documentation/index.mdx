## Use a building block on its own

You do not need to adopt the rest of Cratis to use Fundamentals. Start with the [standalone C# concept example](./csharp/index.md#define-your-first-concept), or follow a configuration setting through the [Option, Result, and Catch chapter](./csharp/monads/index.md). The latter needs only a console app and the core NuGet package: no database, host, or service registration.

The platforms offer different building blocks. The .NET `Cratis.Monads` examples do not imply equivalent APIs in TypeScript or Go; choose the platform guide for the package you use.
