in this documentation site; do not infer C# API equivalents.

## Use a building block on its own

You do not need to adopt the rest of Cratis to use Fundamentals. Start with [TypeScript concepts](./typescript/concept_as.md), the [Go domain-value guide](/fundamentals/go/getting-started/), or the [standalone C# concept example](./csharp/index.md#define-your-first-concept).

The platforms offer different building blocks. For example, the C# [Option, Result, and Catch chapter](./csharp/monads/index.md) needs only a console app and the core NuGet package, not a database or host. It does not imply equivalent monad APIs in TypeScript, JVM, or Go.
